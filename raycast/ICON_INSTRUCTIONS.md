# Icon Instructions

The Raycast extension requires an `icon.png` file in the root directory.

## Requirements

- **Size**: 512x512 pixels
- **Format**: PNG
- **Style**: Simple, recognizable icon that represents "moments" or "memories"

## Suggestions

You can create an icon using:
- A clock/watch symbol (representing moments in time)
- A star or sparkle (representing memorable moments)
- A notebook or journal (representing capturing moments)
- A camera or snapshot (representing capturing memories)

## Quick Setup

1. Create or download a 512x512 PNG icon
2. Save it as `icon.png` in the `raycast/` directory
3. The icon will be used in Raycast's command palette

## Temporary Solution

For now, you can use any 512x512 PNG as a placeholder. Here are some options:

1. **Generate online**: Use https://icon.kitchen/ or similar tools
2. **Use emoji**: Create a 512x512 image with an emoji like ⭐ or 📝
3. **Design custom**: Use Figma, Sketch, or any design tool

Place the final icon as:
```
raycast/icon.png
```
